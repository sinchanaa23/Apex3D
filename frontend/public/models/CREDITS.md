# Hero car model

`car.glb` is derived from **Car Concept** by the Khronos Group, from the glTF Sample Assets
(https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept).
Khronos' version was optimised from a public domain model by Unity Fan
(https://sketchfab.com/3d-models/free-concept-car-004-public-domain-cc0-4cba124633eb494eadc3bb0c4660ad7e).

Licence: Creative Commons Attribution 4.0 International (CC BY 4.0),
https://creativecommons.org/licenses/by/4.0/. The licence excludes Khronos logos and trademarks.

Changes made for Apex3D: removed the interior, engine, wipers and underside, removed all
textures and materials (so the Khronos logos are not present), baked node transforms into the
geometry and welded vertices. Materials and shading are created in code.
